# Aria 3D

The 3D world shares the frame with 2D UI: one `Camera3d`, some lights, meshes, then any overlay divs.

```tsx
import { Bloom, Text3D } from "./aria/3d";
import { Camera3d } from "./aria/camera";
import { AmbientLight, DirectionalLight, PointLight } from "./aria/light";
import { Cuboid, Mesh3d } from "./aria/mesh";
import { StandardMaterial } from "./aria/pbr";
import { Quat, Transform } from "./aria/transform";
import { LinearRgba, Srgba } from "./aria/color";

const glow = (hex: string, k: number) => LinearRgba.from(Srgba.hex(hex)).mul(k);
const T = (x: number, y: number, z: number, rx = 0, ry = 0, rz = 0) =>
  Transform.fromXyz(x, y, z).withRotation(Quat.fromEuler("XYZ", rx, ry, rz));

function Scene() {
  const f = useCurrentFrame();
  return <AbsoluteFill style={{ backgroundColor: "#07060d" }}>
    <Camera3d transform={Transform.fromXyz(Math.sin(f * 0.01) * 2, 1.2, 8).lookingAt([0, 0.3, 0])}
              projection={{ Perspective: { fov: (48 * Math.PI) / 180 } }} />
    <Bloom intensity={0.5} threshold={0.9} />
    <AmbientLight brightness={260} color="#8f86ff" />
    <DirectionalLight transform={Transform.fromXyz(4, 8, 10).lookingAt([0, 0, 0])} illuminance={2400} />
    <PointLight transform={Transform.fromXyz(0, 2.5, 3)} intensity={60000} color="#8b5cf6" range={12} />
    <Mesh3d transform={T(0, 0, 0, f * 0.02, f * 0.03, 0)}>
      <Cuboid half_size={[1, 1, 1]} />
      <StandardMaterial base_color="#1b1530" metallic={0.6} perceptual_roughness={0.2} emissive={glow("#22d3ee", 0.6)} />
    </Mesh3d>
    <Mesh3d transform={T(-1.5, 1.6, 0)}>
      <Text3D size={1} depth={0.25}>title</Text3D>
      <StandardMaterial base_color="#ffffff" emissive={glow("#8b5cf6", 2)} />
    </Mesh3d>
  </AbsoluteFill>;
}
```

## Light that reads
- Always an ambient + a key `DirectionalLight` + one coloured `PointLight` near the subject. Faces/fronts toward
  the camera need a fill from the camera side or they sink to black.
- Emissive colour ×2–5 with `Bloom` (threshold ~0.9–1.0) = neon. Keep bloom intensity 0.3–0.6.
- Point light intensities are big numbers (thousands to hundreds of thousands); `range` limits reach.

## Camera
- Move the camera slowly (orbits of ~0.01 rad/frame, dollies over whole scenes). Static 3D looks like a still.
- `lookingAt` a point slightly above the subject's centre; fov 40–55° for product/title shots.

## Building scenes
- Blocky worlds from `Cuboid`/`Cylinder`/`Sphere` groups in `Entity` transforms render reliably and fast.
- Give repeated objects a `key` and derive variety from `hash(i)`, not `Math.random()`.
- Textures: `base_color_texture={staticFile("tex/wall.png")}` with `uv_transform={Affine2.fromScale([4, 2])}` to tile.

## Pitfalls
- Text3D is centred on its transform: place it at x = 0 to centre it, then check a still.
- A light created only in one shot can tint the next shot's first light: keep shot-only lights consistent.
- Render time: simple scenes ~50–150 ms/frame; dense towns 400+ ms/frame. Stills before full renders.
- Dark 3D → render with `aria make … --dark` (deblock) or via PNG frames for the cleanest gradients.
